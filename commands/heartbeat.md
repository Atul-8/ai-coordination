建立心跳自动驾驶（v0.4.0 G7 新增）。参数：`$ARGUMENTS`

## 执行流程

1. **解析参数**：
   - 间隔分钟：`$1`（默认 10）
   - 任务描述：`$2` 至末尾（默认读 todo.md 当前阶段+待办）

2. **组装心跳 prompt**（模板）：

```
心跳勘察（G7 自动驾驶，间隔 ${N} 分钟）：
1. 查当前状态：有无进行中的子代理/后台任务（检查任务列表+工作流运行状态）
2. 有活：不打断——检查各仓未提交的阶段成果，有已完成的可验证成果就 commit+push（用 Write/Edit 工具，token 从 C:\.ai_global\personal_token.yml 读取）
3. 全部空闲：读 todo.md——按当前阶段计划推动下一任务（Agent 工具派发 writer/reviewer/tester/fixer 子代理）
4. 三行内汇报（进行中/本轮提交/下一步）

铁律：
- 禁止创建新的心跳/调度任务
- 禁止打断进行中的子代理
- 同一文件域的任务禁止并行派发
- 验证必须跑实际命令拿 exit code（G5 确定性验证）
```

3. **调用 CronCreate**：
   - `cron`: `*/${N} * * * *`（每 N 分钟）
   - `recurring`: true
   - `prompt`: 上述模板 + 任务描述
   - `title`: `每${N}分钟心跳：${任务描述摘要}`

4. **汇报**：告知用户心跳已建（automationId + 间隔 + 任务摘要 + 下次触发时间）

## 注意

- 用户说「跑一晚上」「挂机推进」「持续推进」时自动触发本命令（无需用户显式调 /heartbeat）
- 心跳 prompt 是固定文本——不能动态改（CronCreate 限制）；动态决策由模型在每轮心跳里读 todo.md 自主判断
- 已有心跳时告知用户（不重复建）
