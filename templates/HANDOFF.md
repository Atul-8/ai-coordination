# HANDOFF — 跨宿主交接卡

> 跨宿主（ZCode ↔ pi）接力开发的唯一现场记录。**G1 接手方必读**；接手完成后把「状态」改为 resumed。
> 一张卡对应一次交出，整卡重写不追加（历史在 git log）；本文件是纯数据，两个宿主的工具链都原生可读。

- 状态: open
- 交出方: （宿主 + session 前 8 位 + 日期时间）
- 接手方: （留空；接手方完成后写「宿主 + session 前 8 位 + 日期时间」）
- 任务: T-NNN [stage:sN]（todo.md 对应行，保持 [~]；接手后用 coord_todo link 重绑本方会话）
- 已完成: （做了什么；证据 = commit hash / 测试命令与输出摘要——禁止无证据的「已完成」）
- 进行中: （半成品状态；未提交变更清单 `git status --short` 原样贴入；尽量先 WIP 提交再写卡，卡片引用 hash）
- 卡点/死路: （踩过的坑、已排除的方向——防接手方重蹈覆辙）
- 下一步: （精确到可直接执行的命令或动作，接手方照做即续上）
- 验证: （证明接上了的最小验证命令 + 期望输出，接手方必跑）
